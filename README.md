# Lenguajes-y-autómatas-1
Repositorio con el proyecto JavaFX y Maven que contiene las prácticas solicitadas por la Chenbau.

. El proyecto se creó con las dependencias básicas y requiere del JDK 27.0.1.0.3 para funcionar las mismas condiciones a cuando se creó.

. Para futuras modificaciones, se debe implementar el directorio de cada práctica, es decir, dentro del archivo "module-info.java" deberás incluir el directorio de donde se encuentre la nueva práctica.
Por ejemplo: opens com.automatas.tec.Practica_X to javafx.fxml; exports com.automatas.tec.Practica_X;

En caso de tener más subdirectorios, deben especificarse para identificar la ubicación de los archivos main
